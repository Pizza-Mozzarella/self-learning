# Spring Boot

Phạm vi: xây API với Spring Boot — controller, validation, xử lý lỗi, cấu hình, vận hành.

## Ô trống (note dự kiến — viết theo thứ tự học thực tế, không bắt buộc theo list)

- Validation với @Valid và thông điệp lỗi
- Exception handling tập trung và ApiResponse
- Config và Profiles: tách cấu hình theo môi trường
- Logging: ghi log sao cho debug được
- Actuator và vận hành ứng dụng
