# Frontend

Phạm vi: phía trình duyệt — kế hoạch sau chương Order: làm frontend tối thiểu gọi API của chính mình.

## Ô trống (note dự kiến — viết theo thứ tự học thực tế, không bắt buộc theo list)

- HTML/CSS/JS cơ bản: đủ để dựng giao diện gọi API
- React cơ bản: component, state, effect
- Gọi API từ frontend: fetch, xử lý response và lỗi

## Quy tắc

- Note mới: file `NN_ten-note.md`, số tiếp theo; không đổi tên file cũ.
- Trạng thái note nằm ở frontmatter: `status: draft` (chưa kiểm chứng hoặc chưa chốt) hoặc `status: published` (đã kiểm chứng bằng code chạy và đã chốt). Đổi trạng thái thì sửa frontmatter, không chuyển thư mục.
