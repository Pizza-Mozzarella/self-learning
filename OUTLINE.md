# OUTLINE: Danh Mục Tài Liệu

Mục lục điều hướng toàn bộ note. Mỗi chủ đề có README riêng liệt kê các ô trống (note dự kiến) — file note thực tế đánh số theo thứ tự được viết, thứ tự đọc xem tại đây.

---

## 1. Vùng Release (`/release`)

Note đã kiểm chứng bằng code chạy.

- [Java Core](release/java-core/README.md) — OOP, Collections, Generics, Streams, Concurrency, JVM.
- [Spring Core](release/spring-core/README.md) — IoC, DI, Bean lifecycle, AOP, Proxy.
- [Spring Boot](release/spring-boot/README.md) — MVC, Validation, Exception handling, Config/Profiles, Logging.
- [JPA & Hibernate](release/jpa-hibernate/README.md) — Mapping, LAZY, N+1, EntityGraph, Cascade, Specification, Persistence Context.
- [Spring Security](release/spring-security/README.md) — Hash mật khẩu, JWT, OAuth2.
- [Database](release/database/README.md) — SQL, ER, mô hình quan hệ, đại số quan hệ, Index, Transaction, dạng chuẩn.
- [Testing](release/testing/README.md) — JUnit, Mockito, MockMvc, Integration test.
- [HTTP & REST](release/http-rest/README.md) — HTTP, thiết kế REST, status code, phân trang, list vs detail.
- [Git](release/git/README.md) — Workflow nhóm, Conventional Commits, branching.
- [Spring Advanced](release/spring-advanced/README.md) — Redis, Upload, @Scheduled/@Async, Swagger/OpenAPI.
- [DevOps](release/devops/README.md) — Docker, deploy, CI/CD.
- [Frontend](release/frontend/README.md) — HTML/CSS/JS, React, gọi API từ frontend.
- [System Design](release/system-design/README.md) — Thiết kế hệ thống cơ bản.

---

## 2. Vùng Temporary (`/temporary`)

Note vừa học, chưa kiểm chứng — cấu trúc thư mục đối xứng với vùng Release, note mới bắt đầu ở đây rồi tốt nghiệp sang Release khi kiểm chứng xong.

- Các chủ đề tương ứng: `java-core`, `spring-core`, `spring-boot`, `jpa-hibernate`, `spring-security`, `database`, `testing`, `http-rest`, `git`, `spring-advanced`, `devops`, `frontend`, `system-design`.
