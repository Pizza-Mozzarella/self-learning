# HTTP & REST

Phạm vi: giao thức HTTP và thiết kế API REST — thứ controller của project đang nói.

## Ô trống (note dự kiến — viết theo thứ tự học thực tế, không bắt buộc theo list)

- Thiết kế REST: tài nguyên, method, status code
- Tách list và detail (đã học): list tóm tắt + phân trang, detail full đồ thị
- Phân trang: page/size và vì sao không fetch join collection trên query phân trang
- Status code: khi nào 200, 201, 400, 404, 409
