# Spring Core

Phạm vi: lõi Spring — IoC container và AOP, thứ đứng sau mọi annotation quen thuộc.

## Ô trống (note dự kiến — viết theo thứ tự học thực tế, không bắt buộc theo list)

- IoC và Dependency Injection: container quản bean thay mình
- Bean lifecycle: khởi tạo, hủy, các hook
- AOP và Proxy (đã học qua @Transactional): proxy bọc bean, self-invocation
- Transaction qua AOP Proxy: readOnly, điểm-vào, rollback
