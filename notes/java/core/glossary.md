# Java Core: thuật ngữ

Mỗi mục là một thuật ngữ với một dòng giải thích. Note link tới đây bằng `glossary.md#tên-thuật-ngữ`.

### Interface
Kiểu chỉ khai báo các method được phép gọi, không nói làm như thế nào. *(draft)*

### Instance
Object thật được tạo ra từ một class cụ thể. *(draft)*

### Functional Interface
Interface chỉ có một method trừu tượng, nên lambda hoặc method reference có thể đứng vào thay một class. *(draft)*

### Lambda
Cách viết gọn của anonymous class cho functional interface: chỉ giữ tham số và thân hàm. *(draft)*

### Method Reference
Cách viết gọn để truyền một method có sẵn như một hàm, ví dụ Integer::sum. *(draft)*

### Anonymous Class
Class không tên, khai báo và tạo instance ngay tại chỗ dùng, kiểu Java cũ trước lambda. *(draft)*
