# Temporary — Note vừa học, chưa kiểm chứng

Vùng nháp: note mới học xong thì viết vào đây trước, theo đúng cấu trúc thư mục của vùng Release (mỗi chủ đề một thư mục cùng tên).

Quy tắc tốt nghiệp: sau khi kiểm chứng bằng code chạy (xem tiêu chí ở [vùng Release](../release/README.md)), chuyển file sang `release/<chủ đề>/` và cập nhật `OUTLINE.md` + README của chủ đề đó.

Note ở đây đọc thì tự kiểm chứng lại, không dùng làm chuẩn trực tiếp.
